# 주거공간 포트폴리오 폴더 예시

폴더명은 자유롭게 정하고, 이 폴더의 `INFORMATION.md`에 아파트명·지역·주소·설명을 작성하세요. `portfolio/주거공간` 아래에 두면 주거공간으로 분류됩니다.

```text
INFORMATION.md
거실/
  거실 사진.jpg
  KakaoTalk_20261008.jpg
주방/
  IMG_0001.jpg
```

프로젝트 안의 폴더명은 리모델링 구역입니다. 각 구역에 임의의 파일명으로 사진을 넣으세요. 사진에 번호별 우선순위는 없습니다.

사진이 없는 상태에서는 사이트 목록에 표시되지 않습니다. 한 번 갱신은 `update-portfolio.cmd`, 변경 자동 감지 미리보기는 `preview-portfolio.cmd`를 실행합니다. GitHub Pages는 `main`에 업로드하면 자동 반영됩니다.
