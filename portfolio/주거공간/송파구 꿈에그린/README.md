# 송파구 꿈에그린

주거공간 프로젝트입니다. 표시 이름·지역·주소·설명은 이 폴더의 `INFORMATION.md`에서 읽습니다. 구역 폴더와 사진도 자동으로 읽어 포트폴리오에 표시합니다.

```text
INFORMATION.md
거실 및 복도 사진/
주방/
현관사진/
```

구역별 JPG 파일명은 그대로 사용하며 번호별 우선순위가 없습니다. `preview-portfolio.cmd` 실행 중에는 사진 변경이 자동으로 HTML에 반영됩니다. 한 번 갱신에는 `update-portfolio.cmd`를 사용하며, GitHub Pages에는 `main` 업로드 후 자동 배포됩니다.
